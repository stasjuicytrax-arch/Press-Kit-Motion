# PressKitMotion: итог по Вордстату и план запуска теста

## 1. Вордстат: вывод
Покупательский спрос в Яндексе почти отсутствует: по нужным фразам «сайт для диджея», «сайт для артиста», «сайт для певца», «портфолио диджея» данных нет, «пресс-кит диджея» 7, «сайт ведущего свадеб» 43, «сайт для ведущего мероприятий» 29, «создать сайт для музыканта» 22 запроса в месяц. Крупные числа («сайт диджея» 1314, «сайт тамады» 573, «пресс-кит» 1176) это посторонний смысл (скачивание музыки, алкомаркет, госпресс-кит).
**Решение: Яндекс Директ в тесте не запускаем, его бюджет уходит в ВК и посевы.** Ограничение: Вордстат в момент проверки показывал баннер о временной недоступности части данных, не все «заказать…»-фразы проверены. Если захотите, перепроверим позже.
Файл: semantika_wordstat.csv.

- Текст В1: Одна ссылка вместо папки с фото и PDF. Анимированный сайт со скроллом для ведущего мероприятий и свадеб. От 10 000 ₽.
- Заголовок В2: Клиент выбирает ведущего за минуту
- Текст В2: Твои лучшие видео, отзывы и кнопка «Написать» на одной странице. Сайт за 7 дней (срок уточнить). От 10 000 ₽.
- Пост в Телеграм для ведущих: адаптируйте пост для диджеев: «пресс-кит диджея» заменить на «сайт ведущего», пример оставить DJ Nagoo пока нет примера для ведущих. **Лучше сделать хотя бы один пример для ведущих до запуска.**
- Аудитории ВК для ведущих: сообщества ведущих и тамад, свадебные агентства, организаторы мероприятий, ивент-агентства, свадебные паблики. Проверить размер в кабинете.
- Каналы Телеграм: ведущие, ивент, свадебные организаторы.

## 4. Что сделать вам (по шагам)
1. **Самозанятость**: приложение «Мой налог», регистрация. Ставки и лимиты сверьте на сайте ФНС.
2. **Telegram username** для заявок (Настройки → Имя пользователя). Проверьте на телефоне ссылку вида t.me/username?text=Я из ВК.
3. **Продающая страница**: оффер, цена, 5–6 примеров, кнопка в Телеграм, Метрика с целью «Клик по кнопке Телеграм».
4. **Видео 9:16 на 15–20 секунд**: запись скролла djnagoo.site и ещё одного примера. Для ведущих лучше отдельное видео.
5. **ВК Реклама**: вход в кабинет делаете вы. Дальше я заполняю кампании и показываю итог для вашего «да». Данные для маркировки: статус (самозанятый), ФИО, ИНН, ссылка, описание рекламы.
6. **Посевы**: отправляем письмо админам (в teksty.md), собираем цены и охваты, выбираем 1–2 канала, согласуем текст.
7. Оплату и пополнение баланса делаете только вы.
