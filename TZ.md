# ТЗ: лендинг Press Kit Motion

Версия 1.0 · 2026-10-20 · заменяет мини-ТЗ `TZ-landing.md` (оставлен для истории).

Читать вместе с:
- `PRODUCT.md` — продукт, аудитория, ограничения (формат Impeccable).
- `DESIGN.md` — дизайн-система, единственный источник стилей.
- `palettes.html` (артефакт) — выбрана палитра 3 «Кислота».

## 1. Что делаем

Одностраничный продающий сайт услуги «анимированный сайт-пресс-кит для диджея и артиста». Человек приходит из ВК Рекламы или поста в Телеграм-канале, смотрит живые сайты артистов, примеряет пресс-кит на своё имя и пишет в Телеграм **@stasjuicytrax**.

Единственное целевое действие: клик по кнопке «Написать в Телеграм». Всё остальное на странице подводит к нему.

Впечатление: ультрасовременно, светло, много воздуха, технологично, 3D, жидкое стекло, вау с первого экрана.

## 2. Аудитория и трафик

- Русскоязычные диджеи, электронщики, вокалисты, ведущие; промоутеры как вторичная аудитория.
- Трафик в основном с телефонов. Вёрстка mobile-first: 360–430px, потом 768, 1024, 1440.
- Язык русский. Тексты лежат в `src/content/ru.ts`, чтобы позже добавить `en.ts` и маршрут `/en/` без переделки компонентов.

### 6.1 Записи сайтов артистов (главный визуал)

Создать `scripts/record-sites.mjs` (Playwright + ffmpeg). Для каждого сайта:

| Ключ | URL | Подпись |
|---|---|---|
| nagoo | https://djnagoo.site | DJ Nagoo · Санкт-Петербург |
| lolly | https://djlolly.site/ | Lolly · Янгон · Bass, DnB |
| kingdom | https://stasjuicytrax-arch.github.io/39Kingdom/ | 39 Kingdom · дуэт · melodic techno |
| sunrise | https://stasjuicytrax-arch.github.io/djsunrise/ | Sunrise · Бангкок, Паттайя |
| toropov | https://stastoropov-site.vercel.app/ | Стас Торопов · Пермь · ведущий |

Подписи сверить с самими сайтами при записи.

Что записать:
1. **Мобильная запись** 390×844, плавный автоскролл первых 3–4 экранов, 10–12 секунд.
2. **Десктопная запись** 1440×900, автоскролл, 10–12 секунд.
3. **Постеры**: первый кадр каждой записи, AVIF + JPG.
4. **Кропы блоков** для карусели «Что внутри»: первый экран, цифры, видео, галерея, букинг (скриншоты элементов по селекторам или по координатам).

Сжатие: MP4 H.264 (CRF 28, без звука, `-movflags +faststart`) + WebM VP9, ширина 720px для мобильных, 1280px для десктопных; каждый ролик до 1.5 МБ. Класть в `public/media/sites/<key>/`.

### 6.2 Прочее

- Фавикон: лаймовый круг с чёрными буквами PKM, SVG + PNG 180.

### 7.1 Первый экран (Hero) — «Монумент сквозь ленту»

**Утверждение:** это анимированные сайты-пресс-киты для артистов, и вот они живые.

**Композиция, десктоп:**
- На фоне `--bg` по центру 3D-лента из 5–7 экранов сайтов артистов (`DESIGN.md` §9), изогнутая к зрителю по краям.
- Сквозь неё через весь экран едет строка «Press Kit Motion ●» размером `--step-mono`, линия на высоте ~40% экрана. Цвет строки решён через `mix-blend-mode: difference` (белый текст): на светлом фоне он тёмный, на тёмных экранах светлый. Так каждое слово читается целиком. Если blend даёт грязный тон, второй вариант: две копии строки, вторая светлая, обрезана `clip-path` по силуэту центрального экрана.
- Под лентой, по центру: подзаголовок `--step-lead`, две строки, до 36 символов в строке.
- Под ним строка фактов `--step-body`.
- Главная CTA: стеклянная кнопка (Liquid Glass) поверх нижнего края ленты, чтобы стекло преломляло экраны. Магнитная.
- Внизу слева на поле страницы: строка «География». Внизу справа: «Смотреть работы ↓» текстовой ссылкой.

**Телефон:** строка 34vw на 26% высоты, лента из 3 экранов (центральный крупнее), подзаголовок 18px по центру, кнопка на всю ширину на 20px выше нижнего края. 3D только если устройство тянет (§9 DESIGN), иначе фолбэк Tilted Grid Hero с постерами.

**Тексты:**
- `h1` (визуально монумент + подзаголовок, семантически одна фраза): «Press Kit Motion — анимированные сайты-пресс-киты для диджеев и артистов». Бегущие копии `aria-hidden`.
- Подзаголовок: «Анимированный сайт вместо PDF. Промоутер открывает одну ссылку и сразу видит, как ты звучишь и выглядишь.»
- Факты: «От {PRICE} ₽ · готово за {DAYS} дней» — `TODO-OWNER` (черновик из мини-ТЗ: от 10 000 ₽, 7 дней).
- CTA: «Написать в Телеграм».
- География: «Сайты для артистов из Петербурга, Перми, Бангкока и Янгона».

**Движение:** сигнатура страницы. Загрузка: сначала текст (без задержки), затем лента выплывает из глубины за 1.4с с `--ease-out`, затем стартует бегущая строка. При скролле лента замедляется, центральный экран едет вперёд.

### 7.2 Проблема — «Заголовок как подпись к панораме»

**Утверждение:** PDF и набор ссылок проигрывают живому сайту.

**Композиция:** секция 100svh. В верхней трети заголовок `--step-head` по левому полю, под ним две короткие подписи рядом (по 2 строки, размер `--step-body`, ширина 260px каждая). Через 40px начинается панорама на всю ширину: горизонтальная лента из десктопных записей всех сайтов подряд, видна верхняя часть, остальное доезжает при скролле. Лента сдвигается влево по мере скролла (scroll-linked, transform).

**Телефон:** заголовок 12vw, подписи в один абзац, панорама 4:5 из мобильных записей.

**Тексты:**
- `h2`: «Промоутер не листает PDF»
- Подпись 1: «Он открывает твою ссылку в Телеграме между делами. У тебя секунд десять.»
- Подпись 2: «За эти десять секунд сайт показывает видео с твоих сетов, цифры и кнопку букинга.»

### 7.5 Примерь на себя — живой конструктор

**Утверждение:** твой сайт будет выглядеть так, и это видно за 10 секунд.

### 7.6 Как это работает — колонка с врезками

**Утверждение:** процесс понятный и быстрый.

**Композиция:** одна колонка 560px, начинается с колонки 5 сетки. Заголовок, затем 4 абзаца, каждый начинается с жирной врезки в `--ink`, остальной текст абзаца в `--muted` (контраст 6.1:1, проходит). После каждого абзаца маленькое доказательство шириной в колонку: кроп реального сайта на этом этапе (бриф → концепт → анимация → готовый сайт на телефоне). Без номеров шагов. Слева от колонки на десктопе липкий тонкий прогресс-бар лаймом, который заполняется по мере чтения (единственная «линия» на странице, она несёт информацию).

**Тексты (сроки `TODO-OWNER`):**
- `h2`: «Как появляется сайт»
- «**Сначала бриф.** Присылаешь фото, биографию, список площадок и ссылки на музыку. Если чего-то не хватает, подскажу, что подойдёт.»

## 8. Телеграм, UTM и аналитика

- Хелпер `src/lib/telegram.ts`: собирает ссылку `https://t.me/stasjuicytrax?text=...`.
- Текст по умолчанию: «Привет! Хочу сайт-пресс-кит.» + место клика (пакет, имя из конструктора) + источник.
- Источник: читаем `utm_source` из URL при входе, сохраняем в `sessionStorage` (в try/catch). `vk` → «Я из ВК», `telegram`/`tg` → «Я из Телеграма», иначе ничего.
- UTM-параметры не ломают страницу и не исчезают при навигации по якорям.
- **Проверить на реальных телефонах**, что `?text=` подставляется в чат с пользователем (iOS Telegram, Android Telegram, Telegram Desktop). Если клиент игнорирует текст, кнопка всё равно открывает чат.
- Яндекс Метрика: счётчик из `VITE_YM_ID`, webvisor по желанию владельца. Цели: `tg_click` (параметр `place`: hero, nav, sticky, builder, price, cta, footer), `portfolio_open`, `builder_used`.

## 10. Производительность

- Первый экран показывает текст сразу; Three.js-чанк и видео грузятся после.
- LCP < 2.5с на мобильном 4G (Lighthouse mobile), CLS < 0.05, INP < 200мс.
- Видео: `preload="none"`, `muted`, `playsinline`, `loop`, запуск через IntersectionObserver, пауза вне экрана.
- Картинки AVIF/WebP с `width`/`height`, `loading="lazy"` везде кроме первого экрана.
- Шрифт: preload кириллического подмножества Onest.
- Слабое устройство или `Save-Data` → без WebGL, без автозапуска видео (постеры + кнопка Play).
- `backdrop-filter` только на фиксированных и небольших элементах (кнопки, навигация, телефон), не на больших прокручиваемых областях.
